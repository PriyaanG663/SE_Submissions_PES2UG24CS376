# Static Code Analysis Issues — `maintenance_system.py`

Below is the comprehensive list of security, bug, logical, and code-style issues identified using **Bandit**, **Pylint**, **Flake8**, and runtime inspection, ordered from **High/Medium** severity down to **Low** severity.

| Issue | Type | Line(s) | Description | Fix Approach |
| :--- | :--- | :--- | :--- | :--- |
| **Insecure temporary file (`B306`)** | Security (Medium - Bandit & Pylint `W1514`) | 37–40 | `tempfile.mktemp()` is deprecated and vulnerable to symlink/TOCTOU race conditions between path generation and file opening. | Replaced `tempfile.mktemp()` + `open()` with `with tempfile.NamedTemporaryFile(mode="w", suffix=".json", delete=False, encoding="utf-8")`. |
| **Bare `except:` clause (`B110` / `W0702` / `E722`)** | Security / Bug (Medium - Bandit, Pylint, Flake8) | 16–17 | Using a bare `except:` catches all exceptions (including `SystemExit` and `KeyboardInterrupt`) and masks specific runtime errors. | Replaced bare `except:` with specific `except KeyError:` and `except ValueError:` handlers and logged descriptive messages. |
| **Mutable default argument (`W0102`)** | Bug (Medium - Pylint) | 9 | `def register_asset(..., logs=[])` shares the same default list across all function calls, causing unintended state accumulation. | Changed default value to `logs=None` and initialized `if logs is None: logs = []` inside the function. |
| **Unvalidated inputs & logical flaws** | Logic Bug (Medium - Manual Inspection) | 50–56 | Empty asset IDs (`""`) were accepted, duplicate IDs (`"FL-01"`) silently overwrote existing machines, negative intervals (`-30`) made newly registered assets immediately overdue, and invalid user date strings crashed `due_for_inspection()`. | Added validation for non-empty and unique `asset_id`s, validated `days > 0` in `change_interval()`, and parsed dates via `datetime.strptime()` inside `update_service_date()`. |
| **Use of `assert` in production logic (`B101`)** | Security (Low - Bandit) | 59 | `assert len(assets) > 0` is stripped out when Python runs in optimized mode (`python -O`), bypassing critical state checks. | Replaced `assert` with an explicit `if not assets: raise RuntimeError(...)` check. |
| **Missing `with` context manager & file encoding (`R1732`, `W1514`)** | Quality / Reliability (Low - Pylint) | 31–33, 38–40 | Files are opened using `f = open(...)` without a `with` statement or explicit `encoding`, risking resource leaks if an I/O error occurs before `f.close()`. | Wrapped file operations in `with open(..., encoding="utf-8") as ...:` blocks. |
| **Global statement & constant naming (`W0603`, `C0103`)** | Code Quality (Low - Pylint) | 7, 27–28 | `SERVICE_INTERVAL_DAYS` uses `UPPER_CASE` constant naming while being mutated via the `global` keyword inside `change_interval()`. | Stored mutable configuration in a module-level dictionary `service_config = {"interval_days": 90}` to eliminate the `global` keyword. |
| **Unused `logging` import (`W0611` / `F401`)** | Style / Quality (Low - Pylint & Flake8) | 2 | `import logging` was imported at the top of the file but never configured or used. | Configured `logging.basicConfig()` in `main()` and used `logging.warning()` and `logging.error()` for validation and error reporting. |
| **Non-PEP 8 naming, f-strings, & formatting (`C0103`, `C0209`, `C0206`, `E302`, `E501`)** | Style (Low - Pylint & Flake8) | 9–45 | `printAlerts` violates `snake_case` naming (`C0103`); `for a in assets:` iterates keys instead of `.items()` (`C0206`); string concatenation used instead of f-strings; missing two blank lines between functions (`E302`); line 10 exceeds 79 chars (`E501`). | Renamed `printAlerts` to `print_alerts()`, iterated with `.items()`, converted outputs to f-strings, added docstrings, and formatted to PEP 8 (< 79 chars/line). |
